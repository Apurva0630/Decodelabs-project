# WanderNote – My Travel Journal 🌍

WanderNote is a simple travel journal website where I can keep and showcase places and travel memories that I would like to remember.

I made this project while learning and practicing frontend development. As it is my first project I wanted to create something simple, clean and easy to use using basic HTML and CSS.

## About the Project

The website has a simple layout with:

- A navigation bar
- A home/hero section
- Places section
- About section
- Contact section
- Simple and clean styling

## Technologies Used

- HTML
- CSS

## What I Learned

While making this project, I practiced:

- Creating a webpage using HTML
- Styling a website using CSS
- Creating navigation sections
- Working with layouts and spacing
- Using VS Code and Live Server
- Uploading my project to GitHub

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run it using Live Server or open the HTML file in a browser.
